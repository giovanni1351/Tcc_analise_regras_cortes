## Inputs and features

Scenes require `scene_id`, `start_sec`, `duration_sec`. Samples require `scene_id`, `time_sec`, `player_count`. Metadata requires `duration_sec`, `fps`, `yolo_stride` for study coverage. Evaluation also requires events with `time_sec` and `label`, metadata `game`, `half`, `competition`, `season`, `height`, and a video identifier. Sort samples by time. Group by scene_id to get size (all rows, including null player counts), mean (ignoring nulls), and fraction of rows whose player_count equals zero (null compares false). Left join to scenes. For each scene, compute the mean player_count of ALL samples in [start-15, start), regardless of scene. If empty, or any player_count in that range is NaN, the preceding mean is NaN. Prefix sums use IEEE double and numpy nancumsum, which may matter at a threshold. See `src/tcc_soccer_highlights/highlight_study.py:27`.

YOLO samples frame 0 and every stride frames, time = frame/fps. Default stride is 5; fps is video metadata, with 25 fallback. At 25 fps stride 5 gives 0.2 s, but neither value is hardcoded in the filter. `player_count` counts only the model class named `player`, lowercased; `goalkeeper` is separately counted and excluded. Scene IDs are assigned using inclusive scene start/end times; later scenes overwrite earlier ones if overlapping. TransNet scene duration is (end_frame - start_frame + 1)/fps. See `src/tcc_soccer_highlights/batch_analysis.py:20`, `:47`, `:116`, `:164`, `:172`, `:190`, `:204`, `:313`.

## Qualification and proposals

For each scene, require duration <= short, at least 3 sample rows, and start < effective duration. In zero mode, require zero fraction >= zero when use_zero is true; when preceding is true require preceding mean >= 6, hardcoded. In context mode require preceding mean >= min_previous and scene mean <= preceding mean * (1 - drop_fraction); `zero`, `preceding`, and `use_zero` do not affect it. Context validates finite positive min_previous and drop_fraction in [0,1]. Other rule names raise. NaN comparisons fail. See `src/tcc_soccer_highlights/highlight_study.py:46`.

After those conditions, count all initially qualified scene starts in the inclusive interval [start-10, start+10], including the scene itself and duplicate starts. If cluster > 1 retain starts with count >= cluster; otherwise retain all. This is a single pass, not iterative. The code maps qualifying starts back to scenes by equality. Sort retained starts. For each start a, create [max(0,a-before), min(duration,a+after)]. Merge overlapping or touching intervals in order, extending the end to the maximum. before and after must be finite, nonnegative, and sum to > 0. There is no explicit start >= 0 guard. See `src/tcc_soccer_highlights/highlight_study.py:68` and `:83`.

Empty scenes yield no windows if expected columns exist. Scenes without samples fail size >= 3. First scene generally has no previous samples and fails when preceding is required, though earlier samples could exist in unusual inputs. A scene at or beyond effective duration cannot anchor. Windows stop at effective duration, not necessarily the full video. When no samples exist the study excludes the entire video, rather than interpreting missing detections as zero (`highlight_study.py:15`).

Config C is `short=25`, `zero=0`, `cluster=1`, `preceding=true`, `before=10`, `after=16`, `rule=zero`, `min_previous=6`, `drop_fraction=0.65`. short is the inclusive scene-duration limit in seconds; zero is the minimum zero fraction; cluster is the inclusive nearby qualifying-start count; preceding enables the hardcoded six-player minimum; before and after set seconds around scene start; rule selects zero or context; min_previous and drop_fraction configure context only. In C the zero test is tautological for a qualifying scene, cluster=1 performs no filtering, and min_previous and drop_fraction are unused. `use_zero` defaults true and is absent from saved C. See `saved_rules/configurations.json` entry named `redução de 31 e 91 de recall`, and `highlight_study.py:46`.

## Metrics and dataset

Canonicalize by (competition, season, game, half), selecting the highest height among nonempty sample sets, with first encountered winning height ties. Sort distinct string game names lexicographically. If at least six games exist, test uses indexes 0,3,6,..., and all other games train; otherwise test is empty. A game name shared across competitions also shares its split. For each chosen video, effective duration is min(metadata duration, last sample time + stride/fps). Keep events in [0, effective duration] inclusive. See `highlight_study.py:15` and `:152`.

Recall is total target events intersecting at least one merged interval after expanding the event to [time-delta,time+delta], divided by total target events. Touching endpoints counts. Temporal reduction = 1 - sum merged interval durations / sum effective durations. Proposal precision = merged intervals intersecting at least one expanded target event / total merged intervals. Count each event once for recall and each proposal once for precision. Empty denominators return NaN; delta must be finite and nonnegative. See `highlight_study.py:100`, `:106`, `:130`; saved summary construction is in `src/tcc_soccer_highlights/saved_rules_dashboard.py`. C uses delta 0 and labels Foul, Goal, Offside, Shots off target, Shots on target, not the `TARGETS` default.
