Highlights API reference

The Highlights API is a local HTTP service. It takes a soccer video and returns timestamped highlights. It listens on http://127.0.0.1:3000, takes and returns JSON, and has no authentication. To install and start it, see Run the Highlights API locally.

Pipeline

A job runs seven stages in order. Every stage runs on your machine except verdicts.

  1. probe
  2. scenes
  3. detections
  4. windows
  5. segments
  6. verdicts
  7. highlights

verdicts calls a multimodal model on OpenRouter.

The server caches each stage's output under a key. The key hashes the stage name, its version, its parameters, and its inputs. A job reuses every stage whose key already has a finished output.

StageOutputThe key changes when
probeMedia hash, duration, frame rate, and frame count, from ffprobe.The file's bytes change.
scenesScene cuts from TransNetV2.The media or the TransNetV2 weights change.
detectionsYOLO counts of players, goalkeepers, referees, and the ball, on every 5th frame.The media or the YOLO weights in best.pt change.
windowsTime ranges that the rule keeps.spec.rule changes.
segmentsMP4 clips cut from the windows.spec.segmentation or the encoder settings change.
verdictsOne model answer per clip.The model or the prompt version changes. An answer for a clip with the same bytes is reused across jobs.
highlightsEvents in video time, merged across clip overlaps.The verdicts, the windows, or the source's half change.

GET/jobs/:id

Returns the Job: its state, the progress of each stage, the device each CV stage ran on, its coverage, and its paid cost. Clients poll this endpoint for progress.

{
	"id": "1e1b2272-cdb2-4ea3-aebc-564b56341e08",
	"state": { "_tag": "Running", "stage": "verdicts", "done": 1, "total": 56 },
	"stages": [
		{ "stage": "detections", "key": "068dd7bc…", "done": 1, "total": 1, "device": "cuda" }
	],
	"coverage": { "segments": 56, "valid": 1, "invalid": 0, "ambiguous": 0, "notSent": 0 },
	"committedUsd": 0.0012,
	"reservedUsd": 0.08
}

The example leaves out spec, sourceId, createdAt, updatedAt, and six of the seven stages.

POST/jobs/:id/cancel

Cancels a Queued or Running job. The server kills the job's ffmpeg and CV subprocesses. Finished stage outputs stay in the cache. Returns 409 for a job that has already finished.

POST/jobs/:id/resume

Requeues a Partial or Failed job. The job skips finished stages and reuses answered calls. Returns 409 for a job in any other state.

Body
{ retryAmbiguous?: boolean }
retryAmbiguous
Allows the job to resend the paid calls that are Ambiguous at the time of the request. The permission covers those calls once. Startup recovery and the end of the verdicts stage clear it.

GET/blobs/:hash

Returns the file stored under a SHA-256 hash. Clips have type video/mp4. Stage artifacts have type application/json. The endpoint supports Range requests.

GET/jobs/:id/evaluation

Returns { windows: [{ start, end }] }, the time ranges in seconds that the rule kept. The evaluation tools use it to compute the recall ceiling.

GET/evaluation/model-rate?model=

Returns { usdPerSecond }, the highest recorded cost per video second for model. The value is null until the model has a recorded call.

GET/budget

Returns the Budget for paid models across all jobs.

JobSpec

The default spec:

{
	"rule": {
		"_tag": "Zero", "short": 25, "zero": 0, "cluster": 1,
		"preceding": true, "use_zero": true, "before": 10, "after": 16
	},
	"llm": {
		"model": "nvidia/nemotron-3.5-super-vl:free",
		"promptVersion": "benchmark-v1",
		"maxCostUsd": 0.1
	},
	"clips": true,
	"segmentation": { "maxSec": 40, "overlapSec": 5 }
}
FieldMeaning
ruleThe filter that runs before the model. Zero is config C from the study. Context takes min_previous and drop_fraction in place of zero, preceding, and use_zero. before plus after must be above 0.
llm.modelAn OpenRouter model id. Ids that end in :free cost nothing.
llm.promptVersionThe prompt and output schema. benchmark-v1 is the only version.
llm.maxCostUsdThe paid-spend cap for this job.
clipsWhen true, each highlight has a clipUrl.
segmentationClip length and overlap in seconds. maxSec is from 10 to 120. overlapSec is under half of maxSec. Optional, default 40 and 5.

Coverage

Counts the job's clips. segments equals the sum of the other four fields after the verdicts stage.

FieldCounts clips that
validGot an answer that matches the output schema.
invalidGot an answer that breaks the schema or stops at the token limit.
ambiguousHad a paid call sent with no reply received.
notSentHad no call sent, because a budget, a quota, or the credit ran out.

Budget

Job states

  • One runner takes one job at a time from the queue.
  • Running carries the current stage and its progress as { stage, done, total }.
  • At startup, the server moves jobs left in Running back to Queued.
  • Cancel moves a Queued or Running job to Cancelled.
  • Failed carries { stage, error }. error.category is one of SourceChanged, Inference, Process, Provider, Persistence, and InvalidInput.

A job ends in Partial when it finishes with clips in notSent or ambiguous. The reason field gives the cause.

ReasonCauseFields
BudgetExceededThe next paid call would pass llm.maxCostUsd or OPENROUTER_BUDGET_USD.capUsd, committedUsd
FreeDailyLimitThe free-model daily quota ran out.retryAfterMs
CreditExhaustedOpenRouter refused the call for lack of credit.message
AmbiguousAttemptsPaid calls were sent and no reply arrived.count

Paid-call attempts

The server records every model call in a ledger before it sends the call.

StateMeaning
ReservedThe call passed the budget check. The ledger holds a cost bound for it.
SentThe request left the server.
AnsweredThe reply is stored. The reported cost replaces the held amount.
FailedOpenRouter returned an error status.
AmbiguousThe call was sent and no reply arrived, after a timeout, a cancel, or a crash. The ledger keeps the held amount.
  • The server never resends an Ambiguous paid call on its own. A resume with retryAmbiguous is the only way to resend one.
  • While a paid call is unresolved, no job sends the same clip bytes to the same model with the same prompt.
  • Paid calls run one at a time. Free-model calls hold $0 and retry on their own.
  • The held amount for a call is its video seconds times the model's highest recorded cost per second, plus 4,096 output tokens.

Configuration

The server reads these environment variables at startup.

VariableDefaultMeaning
TCC_PORT3000The port on 127.0.0.1. The CLI reads it too.
TCC_DATA_DIR~/.local/share/tcc-highlightsThe SQLite database and the blob store. One server at a time can hold a data directory.
TCC_SOCCERNET_ROOTnoneThe SoccerNet download root. Required for SoccerNetHalf sources.
OPENROUTER_API_KEYnoneRequired, except in dev mode.
OPENROUTER_BUDGET_USD0The paid-spend limit across all jobs. At 0, the server refuses every paid call.
OPENROUTER_FREE_DAILY_CAP50Free-model calls per day. OpenRouter allows 1,000 for accounts that have bought $10 or more in credits.
OPENROUTER_RESERVATION_USD_PER_SECOND0.001The cost bound per video second for a paid model with no recorded call.
OPENROUTER_OUTPUT_USD_PER_TOKEN0.00001The output-token price in the cost bound.
TCC_MODELnvidia/nemotron-3.5-super-vl:freeThe model for analyze when no model argument is given. It must be a free model.
CV_DEVICEautoauto, cuda, or cpu. auto picks CUDA when PyTorch finds a GPU.
TCC_DEV_FAKE_STAGESfalseWhen true, fakes probing and every stage. No GPU, ffmpeg, or key is needed.

CLI

The CLI is an HTTP client generated from the same contract. Every command except serve needs a running server.

CommandDoes
pnpm start serveStarts the server and the job runner.
pnpm start analyze <source> [model] [--force]Registers the source and queues a job. <source> is a file path or soccernet:<league>/<season>/<game>/<half>/<resolution>. A paid model must be given as [model].
pnpm start jobsLists jobs.
pnpm start result <job-id>Prints the job's highlights.
pnpm start budgetPrints the paid-spend totals.
