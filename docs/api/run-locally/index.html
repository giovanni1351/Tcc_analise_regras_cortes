Run the Highlights API locally

This guide gets the API server running on 127.0.0.1:3000, with TransNetV2 and YOLO on your GPU or CPU. The model calls go to OpenRouter. The default model is free. For endpoints, types, and settings, see the Highlights API reference.

Check the requirements

You need these tools on the machine that runs the server:

Linux on x86-64The Python environment pins CUDA 12.6 builds of PyTorch. macOS does not install.
Node.js26.13.1Node 26 runs the TypeScript sources directly. There is no build step.
pnpm12.14.0
uvany recentuv installs Python 3.14 if your machine lacks it.
ffmpeg and ffprobeany recentBoth must be on PATH.
NVIDIA GPUoptionalA 45-minute 224p half takes about 5 minutes on CUDA: 95 s for scene cuts and 204 s for detection. The CPU works, with longer runs.

Install the code and the dependencies

  1. Clone the repository and check out the API branch. The branch holds the API until pull request 3 is merged. 
    git clone https://github.com/giovanni1351/Tcc_analise_regras_cortes.git
cd Tcc_analise_regras_cortes
git checkout feat/design-video-analysis-api
  2. Install Node and pnpm at the pinned versions. With mise, one command reads them from mise.toml: 
    mise install

    If you do not use mise, install Node 26.13.1 and pnpm 12.14.0 another way.

  3. Install the JavaScript dependencies: 
    pnpm install
  4. Create the Python environment for the CV worker: 
    uv sync --frozen

    The command creates .venv with PyTorch, Ultralytics, and transnetv2-pytorch. The YOLO weights are best.pt in the repository root. The TransNetV2 weights come with the transnetv2-pytorch package.

  5. Check whether PyTorch sees your GPU: 
    uv run --no-sync python -c "import torch; print(torch.cuda.is_available())"

    Prints True when CUDA works. If it prints False, the CV worker runs on the CPU.

Start the server

  1. Export your OpenRouter key and start the server: 
    export OPENROUTER_API_KEY=sk-or-v1-...
pnpm start serve

    The server logs Listening on http://127.0.0.1:3000. It stores its database and clips in ~/.local/share/tcc-highlights. To use another directory, set TCC_DATA_DIR.

  2. In a second terminal, check that the server answers: 
    curl -s localhost:3000/budget

    Returns {"limitUsd":0,"committedUsd":0,"reservedUsd":0,"ambiguousUsd":0}.

To build a client without a GPU, ffmpeg, or a key, start the server in dev mode. Dev mode keeps the real API and fakes probing and every stage, so jobs finish at once with no highlights:

TCC_DEV_FAKE_STAGES=true pnpm start serve

To force a device for the CV worker, set CV_DEVICE to cuda or cpu before you start the server.

Analyze a video

  1. Queue a job for a video file: 
    pnpm start analyze match.mkv

    Prints the new job, with "state": { "_tag": "Queued" } and its id.

  2. Follow the job until its state is Succeeded or Partial: 
    curl -s localhost:3000/jobs/<job-id>

    While the job runs, state shows the stage and its progress, for example { "_tag": "Running", "stage": "detections", "done": 31000, "total": 73075 }.

  3. Print the highlights: 
    pnpm start result <job-id>

To analyze a SoccerNet half, point TCC_SOCCERNET_ROOT at your SoccerNet download before you start the server. Then name the half as league, season, game, half, and resolution:

pnpm start analyze "soccernet:england_epl/2014-2015/2015-04-11 - 19-30 Burnley 0 - 1 Arsenal/2/224p"

The server reads that half from <root>/england_epl/2014-2015/2015-04-11 - 19-30 Burnley 0 - 1 Arsenal/2_224p.mkv, the layout that the SoccerNet downloader writes.

To change the rule or the clip length, send a spec to POST /jobs as the reference describes. The new job reuses the finished scene cuts and detections.

Use a paid model

The server refuses paid calls until you set a budget. To run a paid model:

  1. Create an OpenRouter key with its own credit limit. Set the limit at least $1.00 above what you plan to spend. OpenRouter refuses video requests when less than $1.00 of credit remains.
  2. Start the server with that key and a budget: 
    export OPENROUTER_API_KEY=sk-or-v1-...
export OPENROUTER_BUDGET_USD=0.50
pnpm start serve
  3. Pass the model as the second argument: 
    pnpm start analyze match.mkv google/gemini-3.1-flash-lite

    A 45-minute half costs about $0.07 with this model.

  4. Check what you have spent: 
    pnpm start budget

A job also stops at its own cap, llm.maxCostUsd, which defaults to $0.10. A job that hits a cap ends as Partial. Resume it with POST /jobs/<job-id>/resume after you raise the cap or the budget.

Run the checks

pnpm test
pnpm typecheck
pnpm lint

One test compares the CV worker with the reference Python on a 60-second clip. It needs CUDA and a video, and skips without them. To run it, point TCC_CV_TEST_VIDEO at a SoccerNet half:

TCC_CV_TEST_VIDEO="<root>/england_epl/2016-2017/2017-01-02 - 18-00 Sunderland 2 - 2 Liverpool/2_224p.mkv" \
	pnpm test apps/server/src/cv
